# Atlas Support AI Agent

A compact, public Technical Support Agent portfolio project showing controlled agent-style investigation rather than a standalone chatbot.

The verified offline path retrieves synthetic knowledge, looks up synthetic customer/service/log evidence, applies explicit context limits, classifies the issue, and enforces deterministic escalation guardrails. `llm_adapter.py` shows an optional programmatic LLM path that reads credentials only from environment variables.

All operational data in this project is fictional.
